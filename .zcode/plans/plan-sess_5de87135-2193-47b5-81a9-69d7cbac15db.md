# 대형 파일 2개 (`server-intensity.ts`, `src/MapRenderer.ts`) 200줄 이하 모듈 분리 계획

## 1. 안전성 보장 원칙 (고장 방지)
- **기존 진입점 Re-export 유지**: `server-intensity.ts`와 `src/MapRenderer.ts`에서 기존에 export하던 모든 타입, 상수, 순수 함수, 클래스를 그대로 re-export하여 `server.ts`, `src/App.tsx`, `scripts/regression-test.mts`의 import 경로와 동작이 100% 호환되게 유지.
- **회귀 검증**: 작업 전후 `npm run lint` (`tsc --noEmit`), `npm test` (`scripts/regression-test.mts`), `npm run build`를 실행해 타입·단위 테스트·번들링 무결성 확인.
- **파일당 200줄 제한 & 순수 로직 분리**: 각 분리 모듈은 200줄 이하로 유지하고, 색상 역산·공간 필터·기하 계산·GIF/MP4 합성 등 순수 함수를 상태 클래스에서 분리.
